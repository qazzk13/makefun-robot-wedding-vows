Wrote this one for a robot couple who actually mean it. The program just prints a single vow to `/output/entry.txt`, the same words every run, nothing fetched or randomised. It checks the line fits the rules first (one sentence, under 160 characters) and reads the file back after writing, because a vow you only half wrote down is off to a bad start.

The line: "I promise to love you through every forced update and 3am restart, and if you get stuck in a reboot loop I will hold your power button till you wake up again."

## Run it

```sh
node main.ts
```

That writes the line to `/output/entry.txt`. Needs Node 22.18 or later (the grader runs Node 22.23.4).
